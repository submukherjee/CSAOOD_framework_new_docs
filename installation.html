Installation

CSAOOD requires Python 3.10 or newer.

git clone https://github.com/submukherjee/CSAOOD_framework_new.git
cd CSAOOD_framework_new
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -e ".[docs,notebooks,test]"

For GPU execution, install the PyTorch build appropriate for the CUDA version on the server before installing CSAOOD. Verify the environment with:

import torch
print(torch.cuda.is_available())
print(torch.cuda.device_count())

The package can also run on a CPU by passing --gpu-ids cpu.

Documentation hosting

GitHub Actions verifies the Sphinx source and stores the generated HTML as a workflow artifact. Generated HTML is published at https://submukherjee.github.io/CSAOOD_framework_new_docs/ from a separate public repository so this source repository can remain private. Sphinx viewcode is disabled to prevent publication of implementation source pages.

The repository also retains .readthedocs.yaml so that it can be imported into Read the Docs Business later if private hosted documentation is required.

Build and inspect the same documentation locally with:

sphinx-build -b html docs docs\_build\html
start docs\_build\html\index.html
