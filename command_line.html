Command line

All run scripts share the same interface. Display all options with --help.

python run_scripts\run_method1_cyclic.py --help

Trend-corrected example

python run_scripts\run_method2_trend_corrected.py `
  --input-dir input_files `
  --output-dir results\trend_corrected `
  --channels acceleration_x acceleration_y acceleration_z `
  --offset-step 100 `
  --search-type fast_symmetric `
  --correction-mode whole_wrapped_level `
  --correction-window 1000 `
  --pair-direction-mode one_way `
  --gpu-ids auto

FFT-difference example

python run_scripts\run_method4_fft_difference.py `
  --channels sensor_x sensor_y `
  --difference-lag 1000 `
  --fft-cost-normalization squared_sum

Omit --clusters to select the cluster count by silhouette score. Supplying --clusters K fixes the top-level count at K.

Unified command

python -m csaood --method fft_original --channels sensor_x sensor_y

Results are placed under results/<method> unless --output-dir is supplied.

Saved outputs

Each run saves distance_matrix_all.csv, offset_matrix_all.csv, independent per-channel distance and offset matrices, clustering assignments, silhouette scores, heatmaps, run settings, and runtime logs. Distance matrices are not duplicated under a similarity-matrix filename.

Use --subcluster-depth N to request N nested within-cluster levels. The default is one; zero disables subclustering.
