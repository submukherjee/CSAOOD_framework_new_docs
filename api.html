API reference

Alignment

Pairwise waveform alignment algorithms.

All public functions use one offset convention: a positive offset moves the moving waveform to the right, as in numpy.roll(moving, offset, axis=0).

Align one waveform pair using any public CSAOOD method.

Parameters:

  • reference (ndarray | Tensor) – Reference waveform.

  • moving (ndarray | Tensor) – Waveform to align.

  • method (str | AlignmentMethod) – One of cyclic, trend_corrected, fft_original, fft_difference, or none.

  • **kwargs – Method-specific keyword arguments.

Returns:

Alignment result.

Return type:

AlignmentResult

csaood.alignment.build_offsets(length, step=1, search_type='fast_symmetric')

Build a deterministic grid of signed cyclic offsets.

Parameters:

  • length (int) – Number of waveform samples.

  • step (int) – Positive spacing between tested offsets.

  • search_type (str) – One of right_only, left_only, fast_symmetric, or symmetric. The two symmetric choices cover one nonduplicated cycle; fast_symmetric is retained as a familiar name from the original software.

Returns:

Sorted unique signed offsets containing zero.

Return type:

ndarray

csaood.alignment.exhaustive_align(reference, moving, *, offset_step=1, search_type='fast_symmetric', cost='squared', correction_mode=CorrectionMode.NONE, correction_window=1000, offset_chunk_size=32, return_aligned=True, return_cost_curve=True, device=None)

Align a waveform by explicitly evaluating a grid of cyclic shifts.

Edge correction, when requested, is applied to every candidate shift before its cost is evaluated. This ordering is essential because correction can change which shift minimizes the distance.

Parameters:

  • reference (ndarray | Tensor) – Reference waveform with shape (samples, channels).

  • moving (ndarray | Tensor) – Waveform to align to reference.

  • offset_step (int) – Spacing between candidate shifts.

  • search_type (str) – Candidate offset range; see build_offsets().

  • cost (str) – squared or absolute.

  • correction_mode (str | CorrectionMode) – Intercept-only correction strategy.

  • correction_window (int) – Local leading-window length.

  • offset_chunk_size (int) – Number of uncorrected shifts evaluated together.

  • return_aligned (bool) – Whether to return the complete aligned waveform.

  • return_cost_curve (bool) – Whether to return every candidate offset and cost.

  • device (str | device | None) – Torch device. None uses the input/default torch device.

Returns:

Alignment result containing the global and channel-specific optima.

Return type:

AlignmentResult

csaood.alignment.fft_align(reference, moving, *, difference_lags=None, cost_normalization='squared_sum', return_aligned=True, return_cost_curve=True, device=None)

Align two waveforms using FFT-based circular correlation.

Parameters:

  • reference (ndarray | Tensor) – Reference waveform.

  • moving (ndarray | Tensor) – Waveform to align.

  • difference_lags (int | Sequence[int] | None) – If provided, estimate offsets and distances from channel-wise lag differences. If None, use the original signals.

  • cost_normalization (str) – squared_sum for consistency with exhaustive methods, or legacy_msr for the original FFT scripts’ mean squared residual scale.

  • return_aligned (bool) – Whether to return the complete aligned waveform.

  • return_cost_curve (bool) – Whether to return every cyclic cost.

  • device (str | device | None) – Torch device.

Returns:

Alignment result. For differenced alignment, aligned is the original moving waveform shifted by the offset estimated from its differences.

Return type:

AlignmentResult

Edge correction

Intercept-only corrections for cyclic wrap boundaries.

csaood.corrections.apply_level_correction(shifted, signed_shift, mode=CorrectionMode.WHOLE_WRAPPED_LEVEL, window=1000)

Correct the level discontinuity created by a cyclic shift.

The input must already equal torch.roll(moving, signed_shift, dims=0). The cyclic shift is represented as a right shift of h = signed_shift mod M samples, so the first h observations form the wrapped segment and the splice lies between indices h - 1 and h.

whole_wrapped_level estimates the wrapped level from all first h samples. local_seam_level estimates it from at most window samples immediately before the splice. Both modes estimate the leading level from at most window samples immediately after the splice. The resulting constant is added to the complete wrapped prefix. No slope or taper is introduced.

Parameters:

  • shifted (Tensor) – Shifted waveform with shape (samples, channels).

  • signed_shift (int) – Signed shift used to construct shifted. Positive values denote a right shift.

  • mode (str | CorrectionMode) – whole_wrapped_level, local_seam_level, or none.

  • window (int) – Number of leading-side observations used for level estimation.

Returns:

A corrected copy of shifted. If no correction is required, the original tensor is returned.

Raises:

ValueError – If the input shape, correction mode, or window is invalid.

Return type:

Tensor

Return type:

DistanceMatrices

csaood.matrices.compute_folder_distance_matrices_parallel(input_dir, output_dir, channel_names, *, method=AlignmentMethod.CYCLIC, pair_direction_mode='one_way', gpu_ids='auto', max_files=None, **alignment_kwargs)

Compute distance matrices from CSV files using one process per GPU.

The parent process creates a shared read-only memory map. Each worker owns one GPU and a disjoint collection of unordered pairs, writes an NPZ partial result, and communicates only when all workers have completed.

Parameters:

  • input_dir (str | Path) – Directory containing waveform CSV files.

  • output_dir (str | Path) – Root directory for matrices, logs, and partial results.

  • channel_names (list[str]) – Ordered sensor columns used for alignment.

  • method (str | AlignmentMethod) – One of the public alignment methods.

  • pair_direction_mode (str) – one_way or bidirectional_min.

  • gpu_ids (str | list[int] | None) – auto, cpu, a comma-separated device list, or an explicit list of CUDA device indices.

  • max_files (int | None) – Optional number of alphabetically sorted files to process.

  • **alignment_kwargs – Method-specific options forwarded to csaood.align_pair().

Returns:

Combined and independently optimized per-channel distance and offset matrices.

Return type:

DistanceMatrices

csaood.matrices.prepare_signal_memmap(input_dir, output_dir, channel_names, *, max_files=None)

Convert selected CSV columns to a shared float32 memory map.

Complete selected-channel rows are retained from each file, after which all waveforms are trimmed to the shortest retained length.

Parameters:

  • input_dir (str | Path) – Directory containing waveform CSV files.

  • output_dir (str | Path) – Directory for the memory map and input metadata.

  • channel_names (list[str]) – Ordered numeric columns to extract.

  • max_files (int | None) – Optional number of alphabetically sorted files to use.

Returns:

Memory-map path, array shape, file names, channel names, and input-selection metadata.

Return type:

dict[str, Any]

Raises:

  • FileNotFoundError – If fewer than two CSV files are selected.

  • ValueError – If channels are missing or contain insufficient data.

csaood.clustering.agglomerative_cluster(distance_matrix, *, cluster_count=None, maximum_clusters=10, linkage='average', minimum_cluster_size=1)

Cluster a precomputed matrix using agglomerative hierarchical clustering.

If cluster_count is omitted, the number of clusters maximizing the precomputed-distance silhouette score is selected. Candidate partitions violating minimum_cluster_size are excluded.

Parameters:

  • distance_matrix (ndarray) – Symmetric precomputed distance matrix.

  • cluster_count (int | None) – Fixed number of clusters, or None for selection.

  • maximum_clusters (int) – Largest candidate when selecting cluster count.

  • linkage (str) – single, complete, or average.

  • minimum_cluster_size (int) – Smallest admissible cluster during selection.

Returns:

Clustering labels and silhouette diagnostics.

Return type:

ClusteringResult

High-level pipeline

High-level distance and clustering workflows.

csaood.pipeline.run_pipeline(input_dir, output_dir, channel_names, *, method='cyclic', clustering='agglomerative', cluster_count=None, maximum_clusters=10, linkage='average', recursive=True, subcluster_depth=1, embedding_dimensions=10, gpu_ids='auto', max_files=None, pair_direction_mode='one_way', **alignment_kwargs)

Run pairwise distances, default clustering, and standard diagnostics.

Parameters:

  • input_dir – CSV input folder.

  • output_dir – Root result folder.

  • channel_names – Selected numeric waveform columns.

  • method – One of the five public alignment methods.

  • clustering – agglomerative (default) or mds_ward.

  • cluster_count – Fixed number of clusters, or None for silhouette selection.

  • maximum_clusters – Largest candidate cluster count.

  • linkage – Agglomerative linkage for precomputed distances.

  • recursive – Whether to assign one additional subclustering level. Enabled by default to match the iterative hierarchical workflow.

  • subcluster_depth – Number of nested within-cluster levels. The default is one; zero disables nested subclustering.

  • embedding_dimensions – Number of metric-MDS coordinates used before optional Ward clustering.

  • gpu_ids – auto, cpu, a comma-separated string, or GPU IDs.

  • max_files – Optional number of sorted CSV files to use.

  • pair_direction_mode – one_way or bidirectional_min.

  • **alignment_kwargs – Method-specific alignment settings.

Returns:

Tuple of distance-matrix and clustering results.
