Alignment methods

Method 1: exhaustive cyclic alignment

cyclic explicitly evaluates the requested cyclic offset grid. For each offset, it computes the selected all-channel distance and retains the minimum. No boundary correction is applied.

Method 2: trend-corrected cyclic alignment

trend_corrected applies an intercept-only correction to every shifted candidate before calculating its distance. It provides three modes:

  • whole_wrapped_level: estimate the wrapped-side level from the entire wrapped segment and the other level from a local leading window.

  • local_seam_level: estimate both levels from local windows adjacent to the splice.

  • none: disable correction while retaining the same exhaustive interface.

The correction adds one constant per channel. It does not introduce a slope or taper. pair_direction_mode="bidirectional_min" evaluates both directional corrected distances and retains their minimum; the default one_way mode mirrors one directional calculation for speed.

Method 3: FFT alignment on original signals

fft_original uses the circular cross-correlation identity to obtain the squared-distance curve over every shift in O(T log T) operations. It is typically much faster than exhaustive alignment. Its default distance is the sum of squared residuals, consistent with Methods 1, 2, and 5. Set cost_normalization="legacy_msr" to reproduce the original FFT scripts’ mean squared residual scale without changing the selected offset.

Method 4: FFT alignment on differences

fft_difference first calculates lag differences and then applies FFT cyclic alignment. Differencing removes a constant vertical level and emphasizes changes. The returned aligned waveform is the original moving waveform shifted by the offset estimated from its differences. Command-line runs default to the legacy rate-aware lags: 1000 samples for acceleration and voltage and 500 for magnetic channels. --difference-lag overrides these with one uniform lag.

Method 5: no alignment

none compares each pair at zero offset. It provides the experimental baseline needed to quantify the effect of registration.

Offset convention

Every method returns an offset s satisfying:

aligned = numpy.roll(moving, s, axis=0)

Thus, positive values move the waveform right and negative values move it left.
